# Legacy names

Older instructions (a CLAUDE.md, a plan, a user's habit) may cite skills from the plugins DevOrb replaced. Those skills no longer exist. Read the old name, with or without its `superpowers:` or `/` prefix, as the DevOrb skill beside it, and invoke that one.
